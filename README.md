# SoftBodySim

2D soft-body physics sandbox (position-based dynamics) with a moderngl renderer.

```
pip install numpy pygame numba moderngl mlx
python3 main_opengl.py                 # starts on penrose/evolved 1
python3 main_opengl.py --scene fluid   # any preset; W switches worlds in-app
```

Keys: V view, SPACE pause, [ / ] speed, B grab mode, W worlds, G grid, T trails, ESC quit (full list on the Controls card).
