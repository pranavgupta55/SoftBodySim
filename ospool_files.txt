# Files an OSPool chunk_evolve job needs (agent B, 2026-10-29). One repo-relative path per line; '#' = comment.

#
# How this list was made (after agent A's flat-layout fixes to palettes.py and diamonds_map.py):
#   * dynamic: an audit hook (imports + file opens) in every process of a tiny ospool_evolve run (1 round, 2
#     ChunkPool workers, a whole-map spot check in spawned workers), inside python:3.13-slim on linux/amd64, with
#     ONLY these files flat in cwd: it opened exactly the 19 modules and 2 data files below, exit 0.
#   * static: an ast walk of every import (top-level and in functions) from ospool_evolve.py. The only extra
#     reachable modules are
#       - gpu_backend.py (imports mlx at import time), via solver._make_backend only when a World's backend
#         resolves to "gpu"; the job's workers force EnvConfig.backend = "cpu". EXCLUDED.
#       - ui_style, editor (-> fontDict, which pygame.init()s and loads fonts/*.ttf at import, plus freehand,
#         gravity_dial, peg_layer, scene_io, scene_menu, selection), via palettes._ui(), called only by the app's
#         palette-card drawing code. EXCLUDED.
#   Nothing on this path imports mlx, moderngl, gl_* or initialises a pygame display at import time.
